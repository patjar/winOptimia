# winOptimia

winOptimia est un outil Windows WPF de monitoring, audit et optimisation.

## Branches recommandées

- main : production
- stable : validation
- beta : préversion
- dev : développement

## v4.0 GitHub Edition

Cette version ajoute la phase 1 : infrastructure de mise à jour GitHub.

Fonctions ajoutées :

- Vérification de la dernière Release GitHub.
- Comparaison avec la version locale.
- Canal Stable / Beta.
- Téléchargement de l'asset ZIP de la Release.
- Préparation d'un Updater séparé.
- Fichiers de configuration stable.json et beta.json.

Dépôt cible par défaut : patjar/winOptimia.
